# Security Policy for Ramazing



Here at ramazing, we value your privacy and security to its fullest. We understand your concerns in code implements. When we do this, we have our team look at it. If you spot something, you can help by doing the options below!

## Reporting a Vulnerability

Here is how you are able to help report a vulnerability.

<b>Email:</b> tdltesch@gmail.com or contact someone who can reach out to someone who worked on this project.

<b>Pull request:</b> Make a fork, edit any files, you can upload to this repo and someone will take a look. Refer to PRcheck.md.


## Time limit

This repo is looked over, in codespaces, in github its self. Whenever you ask a request for a change it will take <i>2 business days</i> or the changes will <b>NOT</b> happen.


## Declare

We ask that you can test this change and tell us how it will affect the ramazing. This still has to be confirmed by us but if no problems, we will pass it.



## Safety

We NEVER permit any unsafe malicious code in our files, if you are to send malware or unwanted code to our team, we will decline and this account will be banned from EVER sending any changes to our repo.
